# TODO: Правила работы инструмента "Линии"

- Все точки и линии хранятся в мировых координатах (sight).
- При клике по canvas координаты мыши переводятся в мировые координаты через canvasToSight.
- При отрисовке линий, призрака, подсветки — всегда использовать sightToCanvas.
- Поиск ближайшей вершины реализован через findNearestVertex (максимальное расстояние 15px).
- Ctrl+клик по вершине — добавляет точку и завершает ломаную.
- Обычный клик по canvas — добавляет точку или завершает ломаную.
- Масштабирование и панорамирование не должны влиять на положение линий относительно плоскости.
- Все преобразования координат должны использовать screenPos и screenZoom.
- Логика вынесена в linesTool.js, использовать только её для работы с линиями.
