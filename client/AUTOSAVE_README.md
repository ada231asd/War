# Новые функции редактора прицелов

## Автосохранение

### Описание
Реализована система автосохранения, которая автоматически сохраняет состояние редактора в localStorage браузера. **Автосохранение включено по умолчанию.**

### Функции
- **Автоматическое сохранение**: Каждые 30 секунд сохраняется текущее состояние редактора
- **Восстановление при загрузке**: При открытии редактора автоматически загружаются сохраненные данные
- **Очистка при экспорте**: При успешном экспорте файла автосохраненные данные очищаются
- **Визуальный индикатор**: Показывается статус автосохранения только при активном сохранении
- **Сохранение настроек**: Настройки включения/отключения автосохранения сохраняются в кеше
- **Стандартный прицел**: При первом открытии создается стандартный прицел по умолчанию

### Как использовать
1. **Автосохранение включено по умолчанию** - начните работу сразу
2. При необходимости отключите/включите автосохранение переключателем в меню редактора
3. Все изменения автоматически сохраняются в кеш браузера
4. При аварийном закрытии браузера данные будут восстановлены при следующем открытии
5. После экспорта файла автосохраненные данные очищаются, но настройки сохраняются
6. **Нет надоедливых уведомлений** - индикатор появляется только при сохранении

### Что сохраняется
- Слои (линии, многоугольники, изображения)
- Позиция и масштаб холста
- Настройки сетки
- **Прозрачность слоев** (полностью поддерживается)
- Позиции и размеры изображений
- **Настройки автосохранения** (включено/выключено)

### Что НЕ сохраняется
- Сами изображения (только их параметры)
- Временные объекты в процессе рисования

## Стандартный прицел по умолчанию

### Описание
При первом открытии редактора автоматически создается стандартный прицел для демонстрации возможностей.

### Элементы стандартного прицела
- **Многоугольник**: Темно-серый 6-сторонний многоугольник в правом верхнем квадранте
- **Линии**: Три черные линии от точки (0.5, -0.5) к вершинам многоугольника
- **Прозрачность**: Многоугольник 70%, линии 100%

### Координаты многоугольника
- top-left: (-3, 2)
- top-right: (3, 2)
- far-right: (4, 1)
- bottom-right: (3, -1)
- bottom-left: (-2, -1)
- far-left: (-3, 1)

### Особенности
- Создается только при отсутствии сохраненных данных
- Автоматически сохраняется в автосохранение
- Может быть удален или изменен пользователем
- Служит примером для новых пользователей

## Скрытие панели слоев

### Описание
Панель слоев автоматически скрывается, когда холст полностью пустой.

### Логика работы
Панель слоев показывается только когда на холсте есть:
- Изображения
- Линии
- Многоугольники
- Временные объекты в процессе рисования

### Преимущества
- Чистый интерфейс при начале работы
- Фокус на инструментах рисования
- Автоматическое появление при добавлении объектов

## Прозрачность слоев

### Описание
Полная поддержка прозрачности для всех типов слоев.

### Функции
- **Прозрачность изображений**: Работает как раньше
- **Прозрачность линий**: Новое - применяется ко всем линиям в слое
- **Прозрачность многоугольников**: Новое - применяется ко всем многоугольникам в слое
- **Автосохранение прозрачности**: Все изменения прозрачности сохраняются автоматически
- **Восстановление прозрачности**: При загрузке автосохраненных данных прозрачность восстанавливается

### Как использовать
1. Добавьте объекты на холст (линии, многоугольники, изображения)
2. Используйте ползунок прозрачности в панели слоев
3. Прозрачность применяется ко всем объектам в выбранном слое
4. Изменения сохраняются автоматически

### Технические детали
- Прозрачность применяется через `ctx.globalAlpha`
- Полностью прозрачные слои (opacity = 0) не отображаются
- Прозрачность сохраняется в оптимизированном формате как `o` (opacity)

## Предпросмотр прицела

### Описание
Интерфейс для предварительного просмотра прицела в отдельном окне с использованием данных с холста.

### Функции
- **Кнопка предпросмотра**: "Предпросмотр прицела" в меню редактора
- **Окно предпросмотра**: 800x600 пикселей, по центру экрана
- **Данные с холста**: Отображение всех объектов из слоев редактора
- **Центральные линии**: Горизонтальная и вертикальная линии черного цвета
- **Автоматическое масштабирование**: Читаемое отображение объектов
- **Центрирование**: Объекты автоматически центрируются в окне
- **Прозрачность**: Учет прозрачности слоев
- **Точное соответствие экспорту**: Предпросмотр показывает то же, что будет в .blk файле

### Как использовать
1. Нарисуйте прицел в редакторе (линии, многоугольники)
2. Нажмите кнопку "Предпросмотр прицела" в меню
3. Откроется окно 800x600 с предпросмотром
4. Закройте окно кнопкой "×" или кликом вне окна

### Технические детали
- **Размер окна**: 800x600 пикселей
- **Центр прицела**: x=400, y=300
- **Центральные линии**: Горизонтальная и вертикальная черного цвета
- **Масштабирование**: Автоматическое для читаемого отображения
- **Данные**: Прямое использование слоев редактора
- **Прозрачность**: Поддержка opacity слоев
- **Логика экспорта**: Использует ту же логику, что и generateBlkContent()

### Поддерживаемые элементы
- **Линии**: Все линии из слоя "Линии"
- **Многоугольники**: Все многоугольники из слоя "Многоугольники"
- **Прозрачность**: Учет opacity каждого слоя
- **Центрирование**: Автоматическое размещение объектов
- **Дистанционные метки**: Фиксированные метки от 200 до 4000
